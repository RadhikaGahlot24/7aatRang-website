7aat Rang - Fashion Website 👗

## 📖 Overview
*7aat Rang* is a simple and elegant fashion-themed website built using *HTML and CSS*.  
It showcases traditional and modern wear collections such as sarees, kurtis, and casual wear.  
The website includes a navigation bar, slider, and product gallery to give users a stylish browsing experience.

---

## 🧩 Features
- 🌈 *Responsive Navigation Bar* with Font Awesome icons  
- 🎞 *Image Slider* to highlight fashion collections  
- 🧵 *Product Gallery* for sarees, kurtis, and casual wear  
- 📨 *Contact Section* with email support  
- ⚙ *Footer Section* with quick links and credits  

---

## 🖥 Technologies Used
- *HTML5* – for structure  
- *CSS3* – for styling (linked via project.css)  
- *Font Awesome* – for icons  
- *Marquee* – for animated text scrolling
